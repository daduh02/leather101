# Leather101

Leather101 is a beginner-friendly leathercraft learning site built with Node.js and Express.

Live site: https://leather101.vercel.app

## Site structure

### Home

`/`

Main learning hub covering:

- Leather types
- Tanning types
- Best leather by product
- Leather thickness guide
- Leather cuts explained
- Stitching basics
- Edge finishing guide
- Beginner buying advice

### Starter Kit

`/starter-kit.html`

Dedicated guide for: **What tools do I need?**

Includes:

- Essential starter tools
- Beginner tool priority table
- Tool use cases
- Practical buying advice

### Best Leather

`/best-leather.html`

Dedicated guide for: **Best leather for beginners**

Includes:

- Beginner leather comparison table
- Best first purchase recommendation
- Leather types to avoid
- Navigation back to the rest of the site

### Project Tutorials

`/project-tutorials.html`

Dedicated guide for beginner leather projects.

Current tutorials:

- Simple cardholder
- Key fob
- Bookmark
- Coaster

Each tutorial includes basic steps and simple SVG graphics.

## Tech stack

- Node.js
- Express
- Static HTML
- CSS
- Vercel hosting

## Run locally

```bash
npm install
npm start
```

Open:

```text
http://localhost:3000
```

## Deployment

The site is deployed on Vercel from the GitHub repository.

Pushing changes to the `main` branch should trigger an automatic Vercel redeploy.

Live production URL:

```text
https://leather101.vercel.app
```
